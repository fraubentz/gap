      About

      GAP is a system for computational discrete algebra, here compiled to WebAssembly and run in a Web Worker, with an xterm-pty terminal. Some packages won't load, memory is capped, and a running computation can't be interrupted — Restart is the only way out of a loop.

      Downloaded files are cached in your browser's IndexedDB, so later visits start much faster. Files you create are not kept across reloads or restarts.
